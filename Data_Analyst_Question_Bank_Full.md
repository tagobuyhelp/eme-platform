## Module 1: Microsoft Excel

1. What is the default file extension of modern Excel files?
- A. .xls
- B. .xlsx
- C. .csv
- D. .xlm
Correct Answer: B

2. Which function calculates average?
- A. SUM
- B. COUNT
- C. AVERAGE
- D. AVG
Correct Answer: C

3. Which symbol makes a reference absolute?
- A. #
- B. $
- C. &
- D. %
Correct Answer: B

4. Which function counts numeric values?
- A. COUNTA
- B. COUNT
- C. COUNTIF
- D. SUM
Correct Answer: B

5. What does VLOOKUP do?

- B. Searches vertically
- C. Deletes duplicates
